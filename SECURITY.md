# Politique de sécurité

## Versions maintenues

Seule la dernière version publiée d'Azmo OS reçoit des correctifs de sécurité.

## Signaler une faille

**N'ouvre pas d'issue publique.** Utilise plutôt
[« Report a vulnerability »](https://github.com/AzmoWeb/AzmoOS/security/advisories/new)
(onglet *Security* du dépôt). Décris la faille, comment la reproduire et son impact.
Tu recevras une réponse sous quelques jours.

Le modèle de sécurité et les protections en place sont décrits dans [docs/SECURITE.md](docs/SECURITE.md).
